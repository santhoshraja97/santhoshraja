01 — About

From writing the code to keeping it running.

I started on the development and debugging side — building UI, mobile apps and custom components for a low-code platform. That foundation shapes how I approach reliability today: I understand the code that breaks, not just the dashboards that report it.

From there I moved into cloud computing and the microservices world, and now lead hands-on SRE implementation — making sure every project lines up with industry-standard SRE practice, from SLOs and dashboards to severity management and blameless postmortems.

I've worked with top-tier clients in pharma, life science, banking and unemployment insurance, and I'm always looking for the next hard problem that makes a system more robust.
